# Leaf Reader

A lightweight native comic and image reader for Windows and Android, with optional read-only sharing over a trusted local network.

**Version 2.3 public preview. MIT © 2026 ricefriend. Chinese/English settings and encrypted Android migration backups are implemented. Download installation files from Releases.**

## Download

[Releases](https://github.com/ricefriend/leaf-reader/releases) · [Build instructions](BUILDING.md) · [Migration](MIGRATION.md)

- Windows: run `LeafReader-2.3-preview.exe` directly.
- New Android installations: `LeafReader-Android-2.3-preview.apk` (Android 8.0+).
- Existing test installations: first install `LeafReader-Android-2.3-migration-debug.apk` over the old app, export and verify an encrypted backup, then uninstall and install the preview APK. Restore the backup and grant local folder access again.

Choose Chinese or English in Settings. Optional support: [Ko-fi](https://ko-fi.com/gdbkf); all reading features remain free.

## Features

- Read local image folders and ZIP / CBZ archives, with natural filename ordering.
- A continuous responsive bookshelf with uniform rounded covers, search, sorting and a draggable fast-scroll rail.
- Single-page, left-to-right and right-to-left spreads, and continuous vertical reading.
- Android: vertical reading by default for new books, inertial scrolling, horizontal drag and slide animations, pinch zoom and pan.
- Android: temporarily join the current page with its previous or next page; return to the original reading position afterwards.
- Windows: keyboard and wheel navigation, zoom, fullscreen, bookmarks and spread alignment adjustment.
- Enable sharing only when needed, select authorized folders, pair through a QR code or address and code, and stream images on demand.
- Both Windows and Android can connect to another Windows instance. Saved progress stays on each client.

## Platforms and build

Windows uses WPF / C# targeting .NET Framework 4.8. Android uses native Java, requires Android 8.0 or newer, and targets API 35. The Android app is not a WebView wrapper.

See [BUILDING.md](BUILDING.md) and [android/README.md](android/README.md). The build scripts compile with the Windows framework compiler and Android SDK command-line tools. QR dependencies and their licenses are included. Signing keys are excluded from the public source archive; a fresh local Android build generates its own development key.

## Sharing

On Windows, open sharing settings, add the folders to expose and start the service. Connect an Android or Windows client using the displayed private-network address and pairing code. Images are requested individually; the client does not need to copy a whole remote book before reading.

The sharing service is off by default and exposes read-only endpoints. Plain HTTP is intended for trusted LAN / private VPN addresses. Cross-network access requires protected HTTPS or a private VPN. There is no automatic public port forwarding, cloud account or hosted storage.

## Current limits

- The desktop implementation currently supports Windows only.
- Leaf Share v1 is its own protocol; Komga, OPDS and SMB compatibility is not implemented.
- Reading progress is not synchronized between devices.
- Android format support depends on system decoders; compatible remote previews may be generated by the server.
- Opening a book reads image dimensions in the background; very large folders or archives can take time.
- Phone-to-PC connectivity has been confirmed by the user. Version 2.3 passed 66 Android 12 emulator checks, 6 certificate migration checks and 7 JVM model checks, including 630 spread scenarios. This does not establish real-phone frame rates or complete device compatibility.
- Version 2.3 provides separate migration and private-certificate preview APKs. Export and verify an encrypted backup before uninstalling the old development build; local folder permissions must be granted again. See [migration instructions](MIGRATION.md).
