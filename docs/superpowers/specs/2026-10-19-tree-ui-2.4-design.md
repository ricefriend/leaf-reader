# Leaf Reader 2.4 设计：可下钻的目录树书架与桌面端现代化

日期：2026-10-19  
状态：待用户确认  
范围：Windows 桌面端 UI 重做；Windows / Android 两端“按来源分组”支持任意深度目录；版本 2.4.0。

## 1. 背景

当前书架的“来源”只有一层：导入的根目录就是 `SourceKey`，进入来源后所有子目录被拍平成书。真实漫画库常见 `漫画/作品A/第01卷/`、`漫画/作品B/番外/` 这样的多层结构，平铺后既难找，也看不出层级。

同时，安卓端已经做过一轮现代化，Windows 端仍是 2.3 的扁平深蓝界面。用户已从三版草图中选择 **C：宽屏用自动收起的目录树，窄屏用面包屑下钻**（草图见对话中的 `layout-directions.html`）。

## 2. 目标与非目标

### 目标

1. 导入根目录后，分组模式可以沿子目录逐级进入，直到真正装图片的目录；层级不限。
2. 每一层都能看到子目录卡片、当前目录自己的书；返回上一层和任意祖先都只需一次点击。
3. Windows 书架整体现代化：默认收起、鼠标移到左侧自动升起的目录树侧栏，清晰的层级、克制的配色、更好的卡片和排版；浅色/深色都成立。
4. 窄窗口自动退化为全宽书架 + 面包屑，不牺牲可用性。
5. 平铺、搜索、排序、阅读进度、书签、来源管理等既有能力不回退。
6. 两端行为一致；安卓只补目录树交互，不重做已现代化的视觉。

### 非目标

- 不改变“每个直接含图片的文件夹 = 一本书”的扫描规则，不引入 series/volume 元数据。
- 不做目录合并、重命名、别名、拖拽排序。
- 不改阅读器的翻页、双页配对、缩放、Webtoon 渲染和共享协议。
- 不做跨设备进度同步、PDF/RAR 支持、云书库。
- 不重做安卓视觉；不新增安卓分享服务端。

## 3. 用户可见行为

### 3.1 来源、目录、书

- **来源**：一次导入的根目录（或一个远程授权根）。同名来源仍按服务器/路径身份区分。
- **目录节点**：来源内任何“直接或间接包含书”的文件夹。只包含空目录的层级不建节点。
- **书**：直接含有图片的文件夹；ZIP/CBZ 是它所在目录下的一本书。书的 `RelativePath` 是它相对于来源根的路径。
- 仍沿用“重叠导入取最具体父来源”的规则：一本书只属于一个来源。

### 3.2 分组模式的下钻

- 书架根（“全部书籍”）显示来源卡片。
- 点击来源卡片进入该来源；显示它的**容器子目录卡片**和**直接位于该来源根的书**。
- **只有还含有下级目录的文件夹才做成目录卡**；直接含图片、没有子目录的叶子目录直接作为书卡显示在上一级，不再额外包一层。这样两层结构就是“来源 → 书”，不会被硬拉成三层。
- 点击容器目录卡片继续进入；每层都按同样规则显示“容器子目录 + 这一层直接/叶子目录的书”。
- 目录卡片显示：目录名、后代书总数、第一本后代书的封面（自然排序）、目录角标。点击只进入，不直接打开书。
- 面包屑：`书架 / 来源名 / 目录 / 子目录 …`，每一段可点击；最后一段是当前位置。
- 返回：面包屑、`‹` 返回按钮、`Esc`/`Backspace` 都回到上一级；到根后 `Esc` 清空搜索或退出阅读（沿用现有优先级）。

### 3.3 混合目录

一个文件夹自己直接有图片、同时还有带书的子目录时：

- 它既是**目录节点**，也是**一本书**。
- 进入该目录后，显示容器子目录卡片、叶子目录直接展开成的书卡，再把“本目录自己的图片”作为一张书卡显示，卡片上带 `本目录` 小标记。
- 不丢失任何图片；用户既可以选择进入更深的卷，也可以直接读这个目录里的图。
- 扫描结果、阅读进度、书签仍以这本书原来的 `Book.Id` 为准，不因树结构改变。

### 3.4 平铺模式

- 根节点平铺：全部书，和现在一致。
- 进入某个目录后切到平铺：显示该目录及其所有后代的全部书（不再显示目录卡片）。
- 这样目录树负责定位，平铺负责“把这一支全部铺开看”。

### 3.5 搜索

- 搜索范围是**当前节点及其后代**；在根节点搜索就是全库。
- 有查询时隐藏目录卡片，直接平铺匹配的书；匹配规则：书名、相对路径（含目录名）、来源名，忽略大小写。
- 结果卡片副标题显示 `来源 / 相对路径`，便于区分同名书。
- 清空搜索回到当前节点，不改变当前层级。
- 搜索为空时，目录层级和排序照旧。

### 3.6 排序

- 书名：自然排序（`2` 在 `10` 前）。
- 最近阅读：书按自身 `LastRead`；目录按后代书里最新的 `LastRead`。
- 未读优先：书按自身；目录按“后代是否全部未读”排序，未读目录在前。
- 创建时间新旧：书按自身；目录按后代书里最大/最小的创建时间。
- 同一层始终“目录卡片在前，书卡在后”；两组内部各自排序。
- 排序选择继续持久化到 `Settings.ShelfSort`。

### 3.7 导航与快捷键

- `Esc`：阅读中退出全屏 → 返回书架；书架内从当前目录返回上一级；根节点清空搜索。
- `Backspace`：书架内返回上一级。
- `Ctrl+F`：聚焦搜索。
- `F5`：重新扫描；尽量保留当前目录。
- 点击面包屑任意祖先直接跳转。
- 侧栏点击来源/目录直接跳转；侧栏只列来源和容器目录，叶子目录作为书显示在父级，不制造空层级；展开箭头只展开/折叠，不改变当前位置。

### 3.8 状态保持

- `Settings.ShelfGrouped`（平铺 / 分组）继续持久化。
- 当前所在目录不持久化（与现在一致）；重新扫描后若该目录仍存在则保留，否则退到最近的仍存在的祖先。
- 侧栏展开状态不持久化；选中路径的祖先自动展开并滚动到可见位置。
- 从阅读器返回书架时保持当前目录和滚动位置。

### 3.9 平铺查看文件夹图片

- 最后一层书卡（本地、多页、非压缩包）右上角显示 `▦` 按钮；点击封面仍然直接进入阅读，互不影响。
- 点击 `▦` 打开该书的“平铺”视图：按原顺序把文件夹内所有图片铺成缩略图网格，缩略图异步加载；点击任意一张关闭网格并从该页开始阅读。
- 单页文件夹、压缩包和远程书卡暂不显示该按钮，避免无意义的网格或未加载的远程分页。
- 网格关闭（`Esc` / 关闭按钮）只返回书架，不改变阅读进度。

## 4. 数据与算法

### 4.1 书增加相对路径

`Book` 增加：

```csharp
public string RelativePath; // 规范化：'/' 分隔，无首尾斜杠；来源根下的书为 ""
```

赋值：

- Windows 本地扫描：`ShelfGroups.AssignLocal` 已经算出所属 root；用 `book.Id` 相对 root 求路径，把 `\` 换成 `/`。
- Windows 压缩包：用压缩包所在目录相对 root；根目录压缩包为 `""`。
- Windows 远程：`RemoteApi.Books` 读取 `/v1/books` 已返回的 `relativePath`。
- Android 本地：`Storage.scanLocal` 由 DocumentsContract 的 document id 去前缀得到路径；压缩包用其所在目录。
- Android 远程：`Api.books` 读取 `relativePath`。

### 4.2 树模型

新增 `ShelfNode` / `ShelfTree`（放在 `ShelfGroups.cs` 或新文件）：

```csharp
sealed class ShelfNode {
  string Key;            // SourceKey + "|" + NormalizeKey(RelativePath)
  string Name;           // 目录名；来源根用 SourceName
  string SourceKey;
  string RelativePath;   // "" 为来源根
  List<Book> Books;      // 直接位于该目录的书
  List<ShelfNode> Children;
  int Count;             // 后代书总数（含 Books）
  DateTime CreatedUtc;   // 后代最大创建时间
  Book CoverBook;        // 第一本后代书（自然排序）
}
```

构建：

1. 按 `SourceKey` 分组。
2. 每个来源建根节点（`RelativePath=""`，Name=SourceName）。
3. 对每本书按 `RelativePath` 的 `/` 分段建链，书挂到末端节点。
4. 自底向上计算 `Count`、`CreatedUtc`、`CoverBook`；子节点按自然名称排序。
5. 来源按名称自然排序。

`Key` 规范化：本地路径按 `OrdinalIgnoreCase` 大写；远程保留原样（服务器身份已区分）。分隔符统一 `/`。

### 4.3 视图数据

`MainWindow` 维护：

- `string shelfGroup`：当前节点 key；`null` 表示“全部书籍”根。
- `List<Breadcrumb>`：由 key 反查祖先链，用于面包屑和侧栏高亮。
- `ShelfNode CurrentNode`：由树查找；失效时向上找最近存在的祖先。

`FilterBooks()` 改为：

- 无搜索：
  - 平铺 → 当前节点所有后代书。
  - 分组 → 当前节点 `Books`（直接书） + `Children` 转成目录 `Book`（`GroupId=node.Key`，`GroupCount=Count`，`Pages=CoverBook.Pages`）。
- 有搜索 → 当前节点后代书中匹配的书，平铺。
- 排序按 3.6 在渲染前完成。

目录 `Book` 复用现有 `Book` 结构（`GroupId`/`GroupCount`），`ShelfGrid` 根据 `GroupId != null` 渲染目录卡，避免引入第二套网格。

### 4.4 兼容

- 旧设置文件：`Roots`、`Books`、`ShelfSort`、`ShelfGrouped` 不变；没有新必填字段。
- 旧阅读进度按 `Book.Id` 保存，不受树影响。
- 旧版没有 `RelativePath` 的远程数据由接口补；本地扫描每次重建。
- 旧版分组状态里的 `shelfGroup` 不持久化，无需迁移。

## 5. Windows 桌面端设计

### 5.1 布局

```
窗口
├─ 顶栏 64px（横跨全宽）：品牌 / 搜索 / 导入文件夹 / 共享 / 服务器 / 设置
├─ 主体
│  ├─ 侧栏 248px（宽屏）     ├─ 内容区
│  │  全部书籍               │  ├─ 工具栏 50px：面包屑 / 排序 / 平铺·分组
│  │  来源                   │  ├─ 标题区：eyebrow、标题、统计、继续阅读
│  │   └─ 来源树             │  └─ 书架网格
│  │  管理来源 / 刷新         │
└─ 状态栏 30px
```

- 宽屏阈值：`ActualWidth >= 1120` 在左侧保留 10px 触发区；侧栏默认收起，鼠标移入触发区时以 190ms 滑入，移出侧栏 420ms 后滑出。窄屏不提供侧栏，内容区用 `‹ + 面包屑` 导航。
- 内容左右边距 26px；书架底部留 24px；网格列数按可用宽度计算。
- 窗口最小尺寸保持 960×640。

### 5.2 侧栏

- 背景比主背景略亮/略暗一层，右侧 1px 分隔线。
- 品牌固定在顶栏左侧；侧栏从顶栏下方开始，不重复品牌。
- 导航：
  - `全部书籍`（总数）
  - `来源` 小节
  - 每个来源一行：可展开箭头、名称、后代书数
  - 每层目录：缩进 14px、展开箭头、名称、后代书数
- 行高 32，圆角 8；悬停浅色背景；选中行使用 accent-soft 背景 + 左侧 2px accent 竖条 + 更亮的文字。
- 折叠箭头单独响应点击，不改变当前选中。
- 内容超出时侧栏独立滚动；鼠标滚轮不冒泡到书架。
- 侧栏默认收起；左侧 10px 触发区、3px 强调色把手提示可展开。滑入 190ms `CubicEase`，滑出 190ms，移出 420ms 后收起；侧栏覆盖内容，不挤压书架列数。
- 侧栏底部固定 `管理来源`、`刷新` 两个文字按钮。

### 5.3 顶栏与工具栏

- 顶栏：品牌固定在左侧、搜索框（胶囊，水印 `搜索书名或文件夹`，右侧 `Ctrl F`）、`＋ 导入文件夹`（accent 实心按钮）、`共享`、`服务器`、`设置`（ghost 按钮）。
- 工具栏：面包屑在左；右侧 `名称排序 ⌄`、`平铺 / 分组` 分段控件。
- 面包屑段之间用 `›`；最后一段加粗；过长时工具栏内部横向滚动或省略中间段（保留首尾），悬停显示完整路径。
- 窄屏工具栏最左是 `‹` 返回按钮。
- 标题区的 `继续阅读` 只在当前节点内有读过的书时显示，打开该节点下 `LastRead` 最近的一本；没有记录时整个按钮隐藏。

### 5.4 卡片

- 尺寸：168×288；封面 168×224（3:4），文字区 64；列间距/行间距 16/18。
- 封面圆角 10，1px 内描边；使用 `Rectangle` + `ImageBrush` 保证圆角裁剪。
- 书卡：
  - 标题 13px SemiBold，单行省略；
  - 副标题 10.5px：`N 页 · 未读` 或 `N 页 · 读至 M 页`；
  - 已读过的书在副标题下加 2px 进度条（accent）。
- 目录卡：
  - 封面用第一本后代书；后面叠两层错位的暗色“纸页”暗示多本；
  - 左上角 `目录` 胶囊角标；
  - 封面底部渐变遮罩 + `N 本`；
  - 标题为目录名；副标题 `N 本 · 点击进入`。
- 混合目录里的“本目录”书：左上角 `本目录` 胶囊，其余与书卡一致。
- 多页本地文件夹书卡右上角加 24×24 `▦` 按钮；点击打开平铺图片网格，不触发书卡本身的阅读入口。
- 悬停：整体上移 2px、边框转为 accent-line、标题略微提亮；120ms，不做重阴影。
- 键盘焦点：2px accent 外框，保持可 Tab 访问。

### 5.6 响应式

- `SizeChanged` 时根据宽度切换触发区；侧栏默认收起，切换不重建书架，也不改变列数（覆盖式）。
- 窄屏隐藏侧栏后，面包屑工具栏保留 `‹` 返回；顶栏仍保留搜索和四个操作按钮。
- 960px 时网格至少 4 列；1220px 宽屏至少 5 列；超宽屏按公式增加。
- 侧栏显示/隐藏不能导致当前滚动位置跳回顶部。

### 5.7 阅读页

- 进入阅读后侧栏、书架工具栏和标题区全部隐藏，阅读区占满内容列；返回书架时恢复当前目录、滚动位置，侧栏保持收起。
- 阅读界面自动隐藏采用 150–200ms 的淡出 + 轻微上下位移；唤出时反向淡入，避免瞬间跳变。
- 只做视觉统一，不改阅读交互：
  - 返回、模式、适应、缩放、全屏按钮改为 9px 圆角 ghost 样式；
  - 标题 18px；页码与缩放标签使用等宽数字；
  - 底部进度条、滑块、书签按钮使用新 accent；
  - 自动隐藏、边缘唤出、`Tab` 行为不变。
- 深色/浅色两套资源继续生效。

### 5.8 空状态与加载

- 空书架：居中品牌标记、`把故事，放进书架。`、说明、`＋ 导入文件夹`、拖放提示。
- 搜索无结果：`没有找到匹配的漫画` + 清空搜索按钮。
- 扫描/打开中的状态仍走底部状态栏；布局骨架不跳动。

## 6. Android

实现状态：2026-10-19 已同步源码（`Models.tree`、SAF `relativePath`、面包屑、叶子目录还原、自适应图标）；本机无 SDK/JDK，未构建 APK、未跑真机。平铺按钮的安卓入口待确认，不在本次实现。

### 6.1 模型与扫描

- `Models.Book` 增加 `relativePath`。
- `Storage.scanLocal`：
  - 由 tree document id 得到每个目录相对根的路径；
  - 书的 `relativePath` 为该目录路径；
  - 压缩包的 `relativePath` 为压缩包所在目录。
- `Api.books`：读取 `relativePath`。
- 新增 `Models.ShelfNode` / `children(...)`，规则与 Windows 完全一致：来源根、直接书、子目录、后代计数、封面取第一本。
- `Models.groups()` 保留为根层兼容入口，内部改用树。

### 6.2 交互

## 10. 风险

| 风险 | 处理 |
|---|---|
| WPF 侧栏 + 大书库性能 | 侧栏按需展开；书架继续只实例化视口附近卡片 |
| 树 key 在重命名/移动后失效 | 失效时回退最近祖先，不崩溃 |
| 重叠导入导致树节点归属歧义 | 沿用最具体 root 规则，一本书只进一个来源 |
| 长路径撑破面包屑 | 中间省略 + 悬停全路径 + 横向滚动 |
| 旧测试依赖旧 UI 类型 | 更新测试钩子，不保留无用的旧控件 |
| 安卓无法在本机构建 | 明确标注未验证；保持改动最小、可审阅 |
| 卡片尺寸/列数改动影响截图测试 | 更新断言与基准截图 |

## 11. 我替你做的决定

1. **混合目录**：既算目录节点，也算一本书；进入后先目录卡，再“本目录”书卡。
2. **搜索范围**：当前节点及后代；根节点即全库。
3. **目录与书的顺序**：目录卡在前，书卡在后。
4. **侧栏展开状态**：默认收起，不持久化；鼠标触发，移出延迟收起；选中路径的祖先自动展开。
5. **安卓范围**：只加目录树、面包屑和目录卡，不重做视觉。
6. **版本**：2.4.0；Windows 出 EXE，安卓源码同步但本机不产 APK。
